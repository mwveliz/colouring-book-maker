# Colouring Book Maker 🎨

Convierte fotos e ilustraciones en láminas listas para imprimir y colorear, con detección automática de trazos y exportación a PDF A4.

## Requisitos

- [uv](https://docs.astral.sh/uv/) (administrador de paquetes y entornos de Python)

## Ejecución

Para iniciar la aplicación con Streamlit usando `uv`:

```bash
uv run streamlit run streamlit_app.py
```

## Formatos soportados

- PNG, JPG, JPEG, WEBP, AVIF
